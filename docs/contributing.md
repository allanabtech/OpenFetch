# Contributing to OpenFetch

Thank you for your interest in OpenFetch! We welcome contributions.

## Process

1. Fork the repository.
2. Create a feature branch.
3. Commit your changes.
4. Submit a Pull Request.

## Code Style

- Use `cargo clippy` and `cargo fmt` for Rust.
- Use `eslint` and `prettier` for TypeScript/React.

## Running Tests

- Rust: `cargo test`
- Frontend: `npm test`
