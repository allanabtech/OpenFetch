OpenFetch is a modern, fast, and extensible download manager built with Tauri and Rust. It gives you the power of traditional download managers with a beautiful, minimal interface and a robust plugin system.

## ✨ Features

| Feature | Description |
| :---: | :--- |
| 🎨 | **Beautiful UI** - A modern, responsive interface built with React and Tailwind CSS. |
| ⚡️ | **Lightning Fast** - Core engine written in Rust for maximum performance and low memory footprint. |
| 🧩 | **Plugin System** - Extend functionality with custom download extractors and handlers. |
| 🌍 | **Cross Platform** - Works seamlessly on Windows, macOS, and Linux. |
| 🔒 | **Privacy First** - No telemetry, no tracking. Your data stays on your machine. |
| 📖 | **Open Source** - Fully open-source under the MIT license. |

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Rust, Tauri
- **Monorepo:** Turborepo, pnpm

## 🚀 Installation

### Windows
```powershell
winget install openfetch
```

### macOS
```bash
brew install --cask openfetch
```

### Linux
```bash
# Debian/Ubuntu
sudo apt install ./openfetch.deb

# Arch Linux
yay -S openfetch-bin
```

## 🎯 Quick Start

1. Download and install OpenFetch for your platform.
2. Launch the application.
3. Paste a URL or use the browser extension to start downloading!
